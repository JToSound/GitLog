## LinkedIn (long-form)

I just shipped improvements to **LogForge** (open-source):  
https://github.com/JToSound/GitLog

### What it does
- Generates changelog/release notes from git commits
- Supports Markdown/JSON/HTML output
- Includes CI-friendly `next-version --json`
- Works with configurable LLM providers and rule-first classification

### Why this matters
Most teams still write release notes manually, which is slow and inconsistent.  
LogForge standardizes this step so releases are faster and easier to communicate.

If your team has a release-note bottleneck, comment your workflow or open an issue.
